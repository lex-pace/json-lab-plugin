一、概述

JSON Lab（以下简称"本插件"）是一款纯前端的浏览器扩展，提供 JSON 美化、JSON 对比、JSON 转表格三类功能。本插件不收集、不存储、不上传任何用户数据到任何服务器。

二、数据处理方式

  • 所有 JSON 内容的处理（解析、格式化、对比、表格转换）均完全在你本地的浏览器内完成，不会发送到任何远程服务器。
  • 本插件没有任何后台服务、没有任何网络请求代码、不集成任何第三方分析或埋点 SDK。
  • 插件内部的页面切换、主题偏好等设置保存在浏览器的 localStorage 中，仅存在于你的本地设备，不会同步到云端。

三、权限说明

本插件申请的最小必要权限及其用途如下：

  • activeTab：仅在你主动点击插件图标时生效，用于读取当前标签页的内容，以提供"自动捕获当前页 JSON"功能。插件不会在后台持续监控任何页面。
  • scripting：配合上一项，按需向当前标签页注入一次性内容脚本来抓取页面中的 JSON 文本。注入是用户主动触发的，不会自动执行。
  • storage：用于在点击插件图标的弹窗与插件主页面之间临时传递已捕获的 JSON 内容（会话级存储），以及保存主题等偏好设置。

四、不涉及的内容

  • 本插件不收集任何个人身份信息。
  • 本插件不使用 Cookie 进行跟踪。
  • 本插件不展示广告、不进行用户行为分析。
  • 本插件不与任何第三方共享数据。

五、免责声明

"自动捕获当前页 JSON"功能依赖读取你当前正在浏览的网页内容。请仅在你信任的页面上使用该功能，并对导入的 JSON 内容自行判断。本插件不对你导入的内容做任何持久化或外发处理。

六、政策变更

如本隐私政策有任何更新，将在本页面及时发布并更新顶部日期。

1. Overview

JSON Lab (the "Extension") is a fully client-side browser extension that provides three features: JSON beautify, JSON compare, and JSON-to-table conversion. The Extension does not collect, store, or transmit any user data to any server.

2. How Data Is Handled

  • All JSON processing (parsing, formatting, comparison, table conversion) happens entirely within your local browser. Nothing is sent to any remote server.
  • The Extension has no backend service, no network request code, and does not integrate any third-party analytics or tracking SDK.
  • Preferences such as active panel and theme are stored in the browser's localStorage, existing only on your local device and never synced to the cloud.

3. Permissions

The Extension requests the following minimum-necessary permissions, used only as described:

  • activeTab: Activated only when you actively click the Extension icon, to read the current tab's content for the "capture current page JSON" feature. The Extension never monitors any page in the background.
  • scripting: Used together with the above to inject a one-shot content script into the current tab to extract JSON text from the page. Injection is user-initiated and never runs automatically.
  • storage: Used to temporarily pass captured JSON content between the popup and the main page (session-level storage), and to persist preferences such as theme.

4. What We Do Not Do

  • The Extension does not collect any personally identifiable information.
  • The Extension does not use cookies for tracking.
  • The Extension does not display ads or perform behavioral analytics.
  • The Extension does not share data with any third party.

5. Disclaimer

The "capture current page JSON" feature reads content from the web page you are currently viewing. Please use this feature only on pages you trust and judge the imported JSON content yourself. The Extension does not persist or exfiltrate any content you import.
