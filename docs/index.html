用得上的功能

工具不多，刚好够用。

JSON Lab 只做三件事：让 JSON 更容易读、让差异更容易找、让数据更容易整理。

JSON 美化

格式化、压缩、排序 Key。树视图可以折叠，也可以搜索路径和值。

  • JSONPath
  • 搜索高亮
  • 大整数保护

JSON 对比

两份数据逐键递归比较，新增、删除、修改分别标出来。

  • 差异路径
  • 忽略字段
  • 交换两侧

JSON 转表格

对象数组自动展平，列头可筛选，支持列显示/隐藏和 Excel 风格筛选，适合临时查看、复制 CSV 或 Markdown。

  • 嵌套展平
  • 列头筛选
  • 列显示/隐藏
  • 表头固定
  • 斑马纹
  • CSV 导出

Chrome 直接安装

Chrome 用户，下载即用。

Chrome 商店需要付费开发者账号，JSON Lab 暂时无法在商店上架。你可以在右侧直接下载官方打包的 .crx 安装文件，无需解压，功能和商店版本完全一致，数据同样全部在本地处理。

  • 下载下方的 .crx 文件（Chrome 插件标准格式，无需解压）。
  • Chrome 地址栏输入 chrome://extensions 并回车，进入扩展管理页。
  • 打开页面右上角的「开发者模式」开关（必需，否则 Chrome 会拦下站外插件）。
  • 把下载好的 .crx 文件拖进扩展管理页，在弹窗里点「添加扩展程序」。
  • 在工具栏拼图菜单里把 JSON Lab 固定住，点图标即可使用。

JSON Lab / Privacy

隐私政策

JSON Lab 是一款纯前端浏览器扩展。你的 JSON 数据只在本地浏览器中处理，不会被上传到服务器。

本地处理解析、格式化、对比、转表格都在当前设备完成。
不上传数据插件没有后台服务，不会把 JSON 内容发送到远程服务器。
权限用途activeTab / scripting 仅用于用户主动触发的当前页 JSON 捕获。
不做跟踪不使用第三方分析、广告或 Cookie 跟踪，也不共享用户数据。

一、概述

JSON Lab 是一款纯前端浏览器扩展，提供 JSON 美化、JSON 对比和 JSON 转表格功能。本插件不收集、不存储、不上传用户数据到任何服务器。

二、数据处理方式

所有 JSON 内容的解析、格式化、对比和转换均在本地浏览器中完成。插件没有后台服务、网络请求代码或第三方分析 SDK。

三、权限说明

  • activeTab：仅在用户主动点击插件图标时读取当前页面，用于捕获页面中的 JSON。
  • scripting：配合当前页捕获功能，按需注入一次性内容脚本。
  • storage：用于临时传递捕获内容和保存主题等偏好设置。

四、不涉及的内容

不收集个人身份信息，不使用 Cookie 跟踪，不展示广告，不进行行为分析，也不与第三方共享数据。

五、免责声明

当前页捕获功能会读取你正在浏览的页面内容，请仅在信任的页面上使用，并自行判断导入内容。
