DEVELOPER TOOLKIT · PRIVACY FIRST

JSON Lab

更快读懂、整理、对比和导出 JSON。所有处理都在浏览器本地完成。

本地处理 零依赖 MV3 开源透明

JSON 美化

把杂乱的 JSON 格式化成可折叠的语法高亮树。

  • 格式化 / 压缩 / 排序 Key
  • 多层级全展开树视图
  • 搜索高亮（精确 / 模糊）
  • 悬停提取 JSONPath
  • 大整数防精度丢失

JSON 对比

逐键递归比较两份 JSON，精准定位差异。

  • 增 / 删 / 改 三类差异高亮
  • 下拉多选忽略指定字段
  • 完整差异路径显示
  • 差异统计徽章

JSON 转表格

对象数组转可视表格，支持嵌套展平。

  • 嵌套对象自动展平（address.city）
  • 表格搜索高亮
  • 导出 CSV / Markdown
  • CSV 带 BOM 支持 Excel

隐私声明

纯前端处理，数据不离开浏览器。导入当前页仅在你点击捕获时读取，不做后台监控；无网络请求、无第三方分析。
